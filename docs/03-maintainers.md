# Maintainers

The repository is maintained mainly by
[@Sunrisepeak](https://github.com/Sunrisepeak); its upkeep and growth need
more contributors and maintainers.

## The path

Start from the simple and from what interests you, and learn a member as you
go:

**use it → introduce and teach it → report issues → fix bugs → improve it →
maintain one or more members**

## What a maintainer does

A member's maintainer carries the member's daily upkeep — issue triage, fixes,
the fixture and CI care on every platform the member claims — and leads its
popularization and ecosystem building: technical articles, videos, tutorials.
Development plus outreach is the core of the role.

## What a maintainer knows

Deep familiarity with the member's module and its application domain. The
member's page in the [index](README.md) states what it does; the
[conventions](01-plugin-development.md) state what every plugin follows.

## Applying

Applications go through the
[maintainer-application template](../.github/ISSUE_TEMPLATE/maintainer-application.yml),
one member per application. An application states contributions to the member
in both categories — technical development, and technical outreach and
promotion — and a maintenance plan that covers both sides. A recommendation
from an existing maintainer of a related member supports it. The original
author of a member accepted into this repository becomes the member's
maintainer; bug fixes and improvements are always welcome before any
application.
